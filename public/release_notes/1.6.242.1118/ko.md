이번 릴리즈에는 모니터링 › 프로세스에서 늘 위에 오는 프로그램을 순위에서 제외하는 「관찰 제외」가 추가되었습니다. 비정상종료의 원인이 집중된 곳을 확인하는 「증상 관계도」도 추가되었습니다. 원격제어 중에는 원격 PC에 복사해 둔 글을 관리자 PC로 가져올 수 있습니다. 화면을 가리는 알림 배지와 통계 막대는 원하는 위치로 끌어서 옮길 수 있습니다. 에이전트 관련 변경은 각 PC의 에이전트가 1.6.242.1182를 받아야 적용됩니다.

> **업데이트할 때 확인할 점이 있습니다.** 서버를 업데이트하는 동안 DB 변환 작업이 진행됩니다. 기록이 많이 쌓여 있을수록 서비스가 중단되는 시간이 길어질 수 있습니다. 「관찰 제외」의 제외 · 해제는 「모니터링 › 프로세스」 메뉴의 관리 권한이 있는 계정만 할 수 있습니다. 권한 관리에 「메뉴가 쓰는 API가 저장된 것과 다릅니다」라는 안내가 표시되면 「권한 재동기화」를 누릅니다.

## 신규 · 모니터링 › 프로세스에서 늘 위에 오는 프로그램을 「관찰 제외」로 순위에서 제외

백신이나 브라우저처럼 모든 PC에 설치된 프로그램이 매일 순위 상위에 표시되면 살펴볼 프로그램이 밀려날 수 있습니다. 이때 순위 오른쪽 위의 「관찰 제외」에서 해당 프로그램을 「오늘」의 부하 프로세스 Top 10과 「실행 목록」에서 제외할 수 있습니다. 최근 7일 동안 매일 10위 안에 든 프로그램에는 「매일 상위」가 표시됩니다. 이 표시를 보고 제외할 프로그램을 고를 수 있습니다. 제외 설정은 회사 전체에 적용되며 같은 창에서 언제든 해제할 수 있습니다.

1. 모니터링 › 프로세스에서 순위 오른쪽 위 「관찰 제외」를 누릅니다.
2. 창 아래쪽의 「관찰 제외 추가」에서 제외할 프로그램을 선택합니다. 「N개 제외」를 누르면 제외됩니다.
3. 카드나 줄에 마우스를 올리면 눈 아이콘이 표시됩니다. 이 아이콘을 눌러 프로그램을 하나씩 제외하고 메모를 남길 수 있습니다.
4. 다시 보려면 같은 창 위쪽 「제외한 프로세스」에서 「관찰 제외 해제」를 누릅니다.

- **매니저** — 제외한 프로그램은 「오늘」 부하 프로세스 Top 10과 「실행 목록」에서만 제외됩니다. 부하 노드 순위 · 프로세스 상세 · 증상에는 계속 표시되며, 프로세스 상세 머리에는 「관찰 제외」 표시가 붙습니다. 창에서 「관찰 제외 프로세스도 순위에 보이기」를 켜면 해당 화면에서만 제외한 프로그램이 다시 표시됩니다. 「관찰 제외」 단추에는 제외한 프로그램 수가 표시됩니다. 보기 권한만 있는 계정에는 제외한 프로그램이 있을 때만 단추가 표시되며, 목록만 확인할 수 있습니다.
- **서버** — 프로그램 버전이 바뀌어도 실행 파일 이름과 회사가 같으면 계속 제외됩니다. 누가 언제 제외 · 해제했는지는 설정 › 자료·이력 › 기간별 감사 로그의 「프로세스」 분류에 기록됩니다. 서버도 함께 업데이트해야 합니다. 제외 · 해제하려면 「모니터링 › 프로세스」 메뉴의 관리 권한이 필요합니다. 권한 관리에 「메뉴가 쓰는 API가 저장된 것과 다릅니다」라는 안내가 표시되면 「권한 재동기화」를 누릅니다.

## 신규 · 증상 › 현황 › 증상 목록에서 비정상종료의 원인이 집중된 곳을 「증상 관계도」로 확인

프로그램이 오류로 갑자기 종료되는 비정상종료가 여러 PC에서 발생하면 「증상 관계도」에서 원인이 집중된 곳을 확인할 수 있습니다. 지난 회차에 블루스크린에 추가한 「증상 관계도」와 같이 오류 코드(예외 코드) · 원인 파일 · Windows 버전 · 기종을 도형으로 연결해 표시합니다. 이를 통해 비정상종료가 같은 모듈이나 같은 Windows 버전에서 발생하는지 확인할 수 있습니다. 원인 파일에는 제품명과 가장 많이 발생한 파일 버전이 함께 표시됩니다. 도형 왼쪽 위의 동그라미를 누르면 오른쪽에 해당 PC 목록과 증상 기록이 열립니다. 기록을 선택하면 증상 상세로 바로 이동할 수 있습니다.

1. 증상 › 현황 › 증상 목록의 「유형」에서 「비정상종료」를 선택하면 「증상 관계도」가 먼저 표시됩니다.
2. 도형 왼쪽 위의 동그라미를 누르면 오른쪽에 「해당 PC」 목록과 증상 기록이 열립니다. 기록을 선택하면 증상 상세로 이동합니다. 같은 동그라미를 다시 누르면 목록이 닫힙니다.
3. 도형을 선택한 뒤 「○○만 보기」를 누르면 해당 도형에 연결된 PC의 증상만 표시하도록 관계도를 다시 그립니다.

- **매니저** — 원인 파일은 해당 PC 수가 많은 순서로 5개만 표시합니다. 「원인 파일 상위」에서 표시 개수를 10개로 변경할 수 있습니다. 나머지 원인 파일은 「그 밖의 원인 파일 N개」로 묶어 표시합니다. 「Windows 버전 · 기종 모두」를 끄면 원인이 집중된 Windows 버전과 기종만 연결합니다. 조회 기간과 「비일상 · 전체」 설정은 증상 목록에서 선택한 값을 그대로 사용합니다. 블루스크린 관계도도 같은 형태로 표시됩니다. 도구는 그림 왼쪽 위에, 범례는 왼쪽 아래에, 「전체 보기」는 오른쪽 아래에 표시됩니다.
- **서버** — 서버는 비정상종료를 예외 코드 · 원인 모듈 · Windows 버전 · 기종별 PC 수로 묶어 집계합니다. 따라서 서버도 함께 업데이트해야 합니다.

## 신규 · 노드 상세 「원격제어」에서 원격 PC에 복사해 둔 글을 관리자 PC로 가져오기

원격제어 중 원격 PC에서 복사한 오류 메시지나 경로를 관리자 PC로 가져오려면 원격제어 화면 [특수키] 패널 맨 아래의 「노드 클립보드 가져오기」를 누릅니다. 원격 PC 클립보드의 글이 관리자 PC의 클립보드로 복사되고 「노드 클립보드 N자 복사됨」이 표시됩니다. 지난 회차까지는 관리자 PC에서 원격 PC로 글을 붙여넣는 기능만 사용할 수 있었습니다. 원격 PC의 글을 가져오려면 파일로 저장한 뒤 원격 탐색기로 내려받아야 했습니다.

1. 노드 상세 「원격제어」에서 화면 상단의 [특수키]를 엽니다.
2. 패널 맨 아래의 「노드 클립보드 가져오기」를 누릅니다. 「노드 클립보드 N자 복사됨」이 표시됩니다.
3. 관리자 PC에서 Ctrl+V를 눌러 붙여넣습니다. 브라우저가 자동 복사를 차단하면 글 상자와 [복사] 단추가 표시됩니다. 이때 [복사]를 누릅니다.

- **원격제어** — 원격제어 중에는 글만 가져올 수 있으며, 한 번에 4,096자까지 가져옵니다. 글이 4,096자를 넘으면 앞부분만 가져왔다는 안내가 표시됩니다. 원격 PC에 잠금 · 로그인 · 관리자 권한 확인(UAC) 화면이 표시되어 있으면 글을 가져올 수 없다는 안내가 표시됩니다. 보기 전용 연결에서는 단추가 표시되지 않습니다. 가져온 글은 서버에 남지 않습니다.
- **에이전트** — 매니저를 업데이트하고, 각 PC의 에이전트도 1.6.242.1182로 업데이트해야 합니다. 그보다 낮은 버전을 사용하는 PC에서는 단추가 흐리게 표시됩니다. 이때 「노드 원격제어 모듈 빌드 177 이상에서만 쓸 수 있음」이 표시됩니다.

## 개선 · 트레이 › 분석가 창에서 연 프로세스 덤프 파일의 결과를 메시지 루프 대기 · 락 대기 · CPU 사용 구역으로 구분해 표시

PC의 트레이 아이콘 메뉴 「분석가」 창에서 멈춤 · 부하가 발생했을 때 수집한 프로세스 덤프 파일을 열 때 씁니다.

- **에이전트** — 결과에 다음 구역이 표시됩니다. 「메시지 루프 대기」에는 창 스레드가 기다리는 대상과 거쳐 간 모듈 및 후킹 정보가 표시됩니다. 「락 대기」에는 기다리는 락과 해당 락을 쥔 스레드가 표시됩니다. 「같은 위치에 멈춘 스레드」 · 「CPU 사용」(모듈별 CPU 시간) · 「프로세스 상태」 · 「WMI 흔적」 구역도 표시됩니다.
- **에이전트** — 덤프 파일 하나로는 원인을 단정할 수 없으므로 덤프에서 확인한 사실만 「소견」으로 적으며, 맨 위 구역 이름이 「진단」에서 「소견」으로 바뀌고 「원인」 꼬리표가 붙지 않습니다. 같은 락을 다시 잡으려다 멈췄으면 「데드락(재진입)」으로 표시하고, 덤프가 아닌 파일을 선택하면 「덤프 파일을 열지 못함」이 표시됩니다. 각 PC의 에이전트가 1.6.242.1182를 받아야 합니다.

## 개선 · 노드 상세 「원격제어」에서 알림 배지 · 통계 막대 위치 이동

원격제어 중 원격 PC 화면 오른쪽 아래의 알림 배지(「원격 제어 중」 또는 「화면 공유 중」과 경과 시간)나 원격제어 화면 왼쪽 위의 통계 막대(fps · Mbps · 누적 · 해상도 · 손실)가 보려는 곳을 가릴 때 씁니다.

- **원격제어** — 배지나 통계 막대를 마우스로 누른 채 원하는 위치로 끌어 옮깁니다. 배지는 관리자가 원격 화면에서 옮길 수 있습니다. 해당 PC 사용자도 배지를 옮길 수 있습니다. 배지 위치는 해당 원격제어 세션 동안만 유지됩니다. 통계 막대 위치는 이 브라우저에 유지되므로 다음에 원격제어를 열어도 같은 위치에 표시됩니다.
- **원격제어** — 배지는 주 모니터에서 작업 표시줄을 뺀 영역 안에서만 움직이고 다른 모니터로는 옮길 수 없으며, 배지를 눌러도 그 PC에서 쓰던 창의 포커스는 그대로입니다. 배지 위에 마우스를 올리면 이동 모양 커서가 표시되고, 이전과 달리 배지 위를 누르거나 휠을 굴려도 그 아래 창에는 전달되지 않습니다. 배지를 옮기려면 각 PC의 에이전트가 1.6.242.1182를 받아야 합니다.
- **매니저** — 창 크기가 바뀌어도 통계 막대는 원격 화면 안에 남고, 끄는 동안의 마우스 움직임 · 누름 · 휠은 그 PC로 전달되지 않습니다. 통계 막대는 매니저만 업데이트하면 옮길 수 있습니다.

## 개선 · 노드 상세 「Live Agent」에서 분석가로 프로세스를 분석할 때 확인 창과 진행 화면 표시

노드 상세 「Live Agent」에서 분석가로 노드 PC의 프로세스를 분석할 때 씁니다.

- **에이전트** — 분석을 시작하면 「약 10초간 노드 PC 의 스레드 동작을 기록합니다」라는 확인 창이 표시됩니다. 분석하는 동안 진행 화면이 표시됩니다. 분석 결과 관계도에는 회사명 · 프로세스 번호 줄 · 스레드 묶음이 함께 표시됩니다.
- **에이전트** — 각 PC의 에이전트가 1.6.242.1167 이상이어야 하며, 그보다 낮은 PC는 확인 없이 이전처럼 분석합니다.
