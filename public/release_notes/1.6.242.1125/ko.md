## 신규 · 노드 › 현황 › 노드 그룹별 현황에서 부서 · 네트워크 · IP 대역별로 이슈와 부하 비교

부서(또는 네트워크 · IP 대역)별로 이슈와 부하가 어디에 집중되는지 한 화면에서 확인합니다. 「그룹 지도」는 그룹마다 전사 평균 대비 배수를 색으로 표시하고, 「그룹 비교」로 선택한 그룹을 나란히 비교할 수 있습니다.

1. 노드 › 현황 맨 아래의 「노드 그룹별 현황」(BETA)을 엽니다.
2. 왼쪽에서 묶는 기준을, 위쪽에서 지표(「이슈」 · 「부하」)와 기간을 선택합니다.
3. 「그룹 지도」에서 배수를 확인합니다. 오른쪽 「주의 노드」를 누르면 주의 노드가 있는 그룹만 표시됩니다.
4. 아래 표는 「상태」 · 「사양」으로 바꿔 보고, 「그룹 비교」로 그룹을 나란히 비교합니다.

- **매니저** — 노드 목록의 「그룹 요약」 보기는 이 화면으로 옮겨졌습니다. 그룹 안에서만 많이 설치된 프로그램이 있으면 「전사 희소 프로그램」도 표시됩니다.
- **서버** — 서버도 업데이트해야 합니다. 프로그램 관련 값은 업데이트한 뒤부터 쌓이므로, 14일 기간이 다 차기까지 최대 2주가 걸립니다.

## 신규 · 모니터링 › 분석 › 부하 분석에서 하루치 전사 부하 보고서 확인

하루 동안 회사 전체 PC가 얼마나 느렸는지 보고서로 확인합니다. 부하 지수 · CPU · 메모리 · 디스크를 노드 1대 평균으로 평소(직전 7일)와 비교하고, 부하를 많이 차지한 프로그램 · 노드 · 부서를 표시합니다.

1. 모니터링 › 분석 › 부하 분석을 열고 날짜를 선택합니다.
2. 「부하 현황」에서 항목별 값을 평소와 비교합니다.
3. 「과점유 프로세스」에서 프로그램을 누르면 오른쪽에 탭별 상세가 표시됩니다.
4. 오른쪽 위 단추로 보고서를 PDF로 내려받습니다.

- **서버** — 서버가 매일 04:00에 전날 보고서를 만듭니다. 업데이트 전 날짜에는 보고서가 없습니다.

## 신규 · 증상 › 현황 › 네트워크 이슈 현황에서 계속 표시되는 대상을 「재확인 제외」로 제외

일부러 차단한 주소나 쓰지 않는 DNS 서버처럼 고칠 필요가 없는 대상이 계속 이슈로 표시될 때 사용합니다. 제외한 대상은 서버가 다시 확인하지 않고 이슈 목록 · 홈 요약에서도 제외되며, 회사 전체에 적용됩니다.

1. 네트워크 이슈 현황에서 이슈를 선택합니다.
2. 오른쪽 패널의 「재확인 제외」를 누르고, 확인 창에서 「제외」를 누릅니다(메모는 선택).
3. 되돌리려면 이슈 목록 머리의 「제외 목록」에서 「해제」를 누릅니다.

- **매니저** — 제외 · 해제 기록은 설정 › 자료·이력 › 기간별 감사 로그의 「네트워크 이슈」 분류에 남습니다. 「재확인 제외」는 관리 권한이 있는 계정에만 표시됩니다.
- **서버** — 서버도 업데이트해야 합니다. 직접 누르는 「재확인」은 제외한 대상에도 보냅니다.

## 개선 · 노드 목록 · 장기 미접속 노드의 분류 탭을 조직도 · 네트워크 · IP 대역 셋으로 정리

노드 목록이나 장기 미접속 노드에서 왼쪽 분류 탭으로 노드를 묶어 볼 때 씁니다.

- **매니저** — 분류 탭은 「조직도 · 네트워크 · IP 대역」 셋이며, 조직도는 따로 켜지 않아도 사용됩니다. 조직도가 없으면 모든 노드가 「미등록」으로 묶입니다.
- **매니저** — 도메인 · OS · 제조사/모델 · 가상 그룹 탭은 없어집니다. 가상 그룹은 노드 › 분류 › 가상 그룹에서 그대로 사용합니다.

## 개선 · 서버의 노드 상태 서비스가 멈춘 뒤 모든 노드가 오프라인으로 표시되던 문제

PC가 켜져 있는데 노드 목록 · 대시보드에 온라인 노드가 0대로 표시될 때 씁니다.

- **서버** — 서비스가 오류로 멈추면 서버가 자동으로 다시 켭니다. 응답한 PC는 온라인으로 돌아옵니다.
- **서버** — 기존에는 정상 종료로 처리되어 손으로 다시 켤 때까지 멈춰 있었습니다. 서버만 업데이트하면 됩니다.

## 개선 · 서버 재연결 뒤 꺼진 PC가 최대 1시간 동안 온라인으로 표시되던 문제

서버가 재시작되거나 연결이 잠시 끊긴 뒤, 꺼진 PC가 노드 목록에 온라인으로 표시될 때 씁니다.

- **서버** — 서버가 다시 연결되면 PC에 상태를 묻고, 응답하지 않은 PC를 2분 안에 오프라인으로 바꿉니다.
- **서버** — 서버만 업데이트하면 됩니다.

## 개선 · 블루스크린 직후 업데이트가 겹쳐 증상 목록에서 블루스크린이 빠지던 문제

블루스크린이 발생한 PC인데 증상 목록에 해당 블루스크린이 없을 때 씁니다.

- **에이전트** — 블루스크린 뒤 덤프 분석이 끝나기 전에는 에이전트가 주기 업데이트를 확인하지 않습니다(최대 약 30분).
- **에이전트** — 각 PC의 에이전트가 1.6.242.1192를 받아야 합니다.
