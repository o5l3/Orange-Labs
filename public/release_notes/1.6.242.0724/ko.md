새로 추가된 위젯은 매니저 대시보드의 **위젯 추가**에서 바로 올려 사용합니다. 대시보드는 증상 · 부하 · 노드 현황을 한 화면에 모아 보는 메인 화면입니다.

## 신규 · 프로세스 — 전사 자원 사용 현황·확산 예측

파일 내용 해시로 식별한 프로세스 한 버전(SUID)을 골라, 회사 전체 기준(baseline) 대비 자원 사용량과 노드 확산을 최초 실행 관측일(firstSeen) 기준 타임라인으로 비교합니다.

- **투데이** — 오늘 전사 부하를 헤드라인으로 요약하고, 부하 프로세스 Top 10과 부하 노드 Top 10을 한 화면에 보여줍니다
- **실행 목록** — 부하지수(전사 CPU · 메모리 · 핸들 합산) 순 정렬, 프로세스명 · 파일 · 제품 · 저작권으로 검색
- **노드 목록** — 선택한 프로세스를 실행한 노드(PC)를 이름 · IP · 상태 · 증상 건수로 확인
- **상세 타임라인** — CPU · 메모리 · 핸들 · I/O를 회사 평균과 겹쳐 보고, 노드 확산 · 증상을 함께 확인. 오늘 시간대별 실시간 보기 지원
- **확산 예측** — 이 프로그램을 쓰는 PC가 앞으로 7일 안에 전사 부하 상위 10% 구간에 들지 매시 예측하고, 예측이 실제로 맞았는지 적중률 · 리드타임 채점표로 검증

## 신규 · 부하 요약

오늘 전체 노드 부하의 고점을 관리자가 바로 이해할 수 있게 문장으로 설명합니다. 숫자 차트를 읽지 않아도 오늘 무슨 일이 있었는지 알 수 있습니다.

- 고점이 언제 · 얼마였고, 어느 프로세스 때문이었으며, 몇 대에 영향을 줬는지 서술
- 직전 1시간 · 어제 같은 시간과 대조해 평소보다 높은지 판단
- **변화 분해** — 접속 노드 수가 늘어난 효과인지, 실제 사용량이 늘어난 것인지 구분

CPU · 메모리 · I/O · 핸들에 디스크 · 유선 · Wi-Fi를 더한 시간대별 부하 추이와, 오늘 고점을 문장으로 풀어 주는 요약 패널을 함께 제공합니다.

## 신규 · 일상 증상 감지 — 일상 분류 검증·설정

서버의 baseline 서비스가 각 증상을 '일상(routine)'으로 볼지 판정한 결과를 표로 검토하고, 항목 상세에서 features와 시계열 차트로 분류 품질을 확인합니다. 반복적으로 나타나는 일상 증상을 자동으로 걸러 두면, 관리자는 중요한 증상에 집중할 수 있습니다.

- 증상을 일상/비일상으로 전역 강제 지정, 판정이 오락가락하는(진동) 항목 우선 정렬, 검토 커버리지 표시
- **설정 › 일상 분류** — 느슨 / 보통 / 엄격 프리셋으로 민감도를 조절하고, 값을 서버에서 바로 편집(재배포 불필요)
- **트레이드오프 안내** — 느슨할수록 반복 증상을 더 많이 숨기지만, 놓칠 위험은 커집니다

## 신규 · 네트워크 — 사무실 구역 자동 인식

각 PC가 어느 사무실 네트워크(구역)에 있는지 자동으로 찾아 보여줍니다. 공유기 MAC · 출구 IP · IP 대역 · 도메인 · 업데이트 서버 같은 신호로 비슷한 PC를 묶어 구역 후보를 제시합니다.

- 여러 사무실이 같은 내부 IP 대역을 써서 자동 구분이 어려운 PC는 '불확실'에 모아 검토를 요청
- '구역 자동 찾기'로 묶음을 확인하고 이름만 붙이면, 미확정 PC가 그 구역으로 자동 분류
- 사람이 지정(pin)한 배정은 에이전트 보고값이 덮어쓰지 못하게 보호

## 신규 · 파일함

파일을 폴더로 정리하고 버전별로 관리하는 파일함이 설정에 추가됐습니다. 증상 리포트 등에서 참조하는 문서를 한곳에서 보관 · 교체하고, 파일함을 통해 파일을 배포할 수도 있습니다.

**설정 › 파일함**에서 시스템 파일과 사용자 폴더를 트리로 정리하고 업로드 · 교체합니다.

## 개선 · 1:N 명령 화면 전면 개편

여러 노드에 명령을 한 번에 보내고 결과를 실시간으로 확인하는 1:N 명령 화면을 새로 설계했습니다. 기존 화면은 **(구)명령관리**로 남겨 두어 이전 방식도 계속 쓸 수 있습니다.

- **명령 구성기** — 명령 타입(WMI · 명령 프롬프트 · PowerShell · SQL · 설치 목록 · 네트워크/OS/모니터/백신/Windows 업데이트 조회 · 에이전트 명령 등) 선택, 쿼리 · 추가 필드 입력
- **대상 · 전송** — 조직도 · 가상 그룹에서 대상 선택, '동적 대상'으로 이후 추가된 노드 자동 포함, 예약 전송 · 만료 · 실패 시 재시도
- **결과** — 노드별 상태 그리드 + 값별 집계 차트, 요약/상세 탭, PDF · Excel 내보내기, 실패 노드만 재전송, 복제 · 템플릿 저장
- **목록** — 카테고리 · 즐겨찾기 · 생성일 필터 · 검색, 템플릿 가져오기/내보내기

## 개선 · 노드 부하 요약 차트 — 10지표 확장

오늘 시간대별 부하 추이 차트가 CPU · 메모리 · I/O · 핸들 4종에서, 디스크 · 유선 · Wi-Fi(각 읽기/쓰기) 6종을 더해 10종 오버레이로 확장됐습니다.

- 10종 지표를 탭으로 전환하며 전일 대비까지 함께 확인
- 실시간 MQTT 갱신과 피크 마커 제공
- 에이전트가 디스크 · 인터페이스별(유선/Wi-Fi) 읽기 · 쓰기 처리량을 새로 수집
