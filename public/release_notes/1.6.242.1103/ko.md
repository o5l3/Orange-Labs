이번 릴리즈에서는 노드 상세 「원격 탐색기」로 PC의 파일과 설치된 프로그램을 매니저에서 바로 관리합니다. 권한은 위젯별이 아닌 메뉴별로 설정합니다. 새 기능 대부분은 각 PC의 에이전트 버전이 1.6.242.1136 이상이어야 동작합니다.

> **업데이트 후 달라지는 점이 세 가지 있습니다.** 권한 관리의 「위젯 권한」 탭이 「메뉴 권한」 탭으로 바뀝니다. 쓰기나 삭제 중 하나만 허용했던 역할에는 해당 메뉴의 등록·수정·삭제 권한이 모두 부여되므로, 업데이트 후 역할별 권한을 재확인하고 저장해 주세요. Live Agent에서 실행한 분석가 결과는 「업로드」한 항목만 남고, 나머지는 2시간 뒤 삭제됩니다. 「부팅 지연」 증상은 이제 만들어지지 않습니다.

## 신규 · 노드 상세 「원격 탐색기」 탭에서 PC의 파일 찾기·올리기·실행

원격제어로 화면을 넘겨받지 않고도 매니저에서 PC의 드라이브와 폴더를 Windows 탐색기처럼 열어, 파일을 찾아 올리거나 실행할 수 있습니다.

1. 노드 상세에서 「원격 탐색기」 탭을 엽니다.
2. 왼쪽에서 드라이브나 폴더를 선택하면 오른쪽에 파일 목록이 표시됩니다.
3. 파일이나 폴더를 마우스 오른쪽 단추로 클릭하면 열기·잘라내기·복사·삭제·이름 바꾸기·속성 메뉴가 표시됩니다.
4. 관리자 PC의 파일을 목록으로 끌어다 놓으면 대상 PC에 업로드됩니다.

- **매니저** — PC에 로그인한 사용자의 바탕 화면과 문서 폴더, 그 사용자가 연결한 네트워크 드라이브까지 그 사용자의 권한으로 열리며, PC가 꺼져 있으면 사용할 수 없습니다. 파일을 실행할 때는 일반 사용자·관리자·시스템 권한 중 하나를, 삭제할 때는 휴지통으로 보낼지 바로 삭제할지를 선택합니다. 해당 PC 안에서 Ctrl+C·Ctrl+X·Ctrl+V로 파일을 복사하거나 이동할 수 있고, 작업에 실패하면 Windows 오류 번호와 오류 내용을 함께 보여 줍니다.
- **서버** — 파일을 변경하거나 실행하는 요청은 서버가 각각 서명해 전송하며, 이 서명은 60초 동안만 유효합니다. 탭을 연 기록과 조작 결과는 감사 기록에 남고, 권한 관리에서 기능 권한 「원격 탐색기」가 부여된 역할만 사용할 수 있습니다.

## 신규 · 명령 관리 「스크립트 마법사」에서 명령을 직접 입력하지 않고 PC 정보 조회·설정 변경

PowerShell 명령을 직접 입력하지 않아도, 원하는 작업을 선택하면 마법사가 여러 PC에 보낼 명령을 만들어 줍니다.

1. 명령 목록에서 「새 명령 만들기」를 누르고 「스크립트 마법사」를 엽니다.
2. 「조회」 또는 「바꾸기」를 선택한 다음 추천 명령에서 원하는 작업을 선택합니다. 추천 목록에 없으면 「모든 명령」에서 찾습니다.
3. 온라인 상태인 PC 한 대에서 명령을 미리 실행하고 결과를 확인합니다. 「바꾸기」는 미리 실행한 뒤에만 명령에 추가할 수 있습니다.

- **매니저** — 추천 명령은 자산 조사·보안 점검·장애 조사·네트워크 분야에 48개가 있으며, PC를 멈추게 할 수 있는 위험한 명령은 선택할 수 없습니다. 명령·스케줄 만들기 화면의 입력 순서도 「누구에게 → 무엇을 → 언제」로 바뀌었습니다.

## 신규 · 모니터링 › 프로세스 「실행 목록」에서 그룹·PC를 선택해 프로세스 부하 분석

전체 PC 기준으로만 표시되던 실행 목록을 조회 기간과 대상(그룹·노드)으로 좁히고, 프로세스 부하를 노드·그룹·날짜·요일·시각별로 묶어 확인할 수 있습니다.

1. 모니터링 › 프로세스의 「실행 목록」 탭에서 「분석」을 누릅니다.
2. 조회 기간, 대상, 묶음 기준을 선택한 뒤 「확인」을 누릅니다.
3. 표에서 부하 지수(합계·노드당)를 확인하고, 프로세스 행을 선택하면 같은 조건으로 해당 프로세스의 상세 화면이 열립니다.
4. 선택한 조건은 「분석」 옆에 표시되며, 「해제」를 누르면 기본 목록으로 돌아갑니다.

- **매니저** — 조회 기간은 최근 7일이 기본이고 최대 14일까지 늘릴 수 있으며, 대상은 한 번에 노드 200대까지 선택합니다. 「시스템 프로세스 포함」을 끄면 Windows 시스템 프로세스와 Windows 공통 영역이 조회 결과에서 제외됩니다. 노드는 상위 그룹에도 포함해 집계하므로 그룹별 수치를 서로 더하면 안 됩니다. 날짜·요일·시각별로 묶인 행을 선택하면 그 조건의 결과만 다시 조회합니다. 프로세스 상세의 「편하게 보기」는 노드별 부하, 날짜별 추이, 노드×날짜 표를 색으로 표시하고, 수치는 마우스를 올리면 볼 수 있습니다.
- **서버** — 서버는 프로세스 부하를 노드×프로세스×시각 단위로 새로 집계해 90일 동안 보관합니다. 조건을 선택하면 이 집계 결과를, 선택하지 않으면 기존과 같이 전체 PC의 집계 결과를 보여 줍니다. 두 기준의 값은 서로 다르므로 목록 위의 「기준」 표시로 구분합니다.

## 신규 · 분석가 「디스크 분석」에서 드라이브별 공간 사용 현황 확인 및 삭제해도 되는 파일 정리 (노드 상세 Live Agent·에이전트 화면)

디스크 여유 공간이 부족한 PC에서 분석가가 드라이브별로 공간을 차지하는 항목을 조사하므로, 삭제해도 되는 파일을 골라 정리할 수 있습니다.

1. Live Agent의 「분석가」 카드를 연 뒤 오른쪽 위의 「디스크 분석」 아이콘을 누릅니다.
2. 결과 아래쪽에서 드라이브별 정리 가능 용량과 큰 폴더·큰 파일을 확인합니다.
3. 맨 위의 「정리」 영역에 모인 항목은 「정리」를 눌러 한꺼번에 삭제합니다.
4. 휴지통이나 사용자 자료처럼 직접 선택해야 하는 항목은 「선택 삭제」 영역에서 선택해 삭제합니다.

- **룰** — 「디스크 여유 공간 부족」 증상이 발생하면 분석가가 해당 드라이브를 자동으로 분석해 「디스크 부족 자동 분석」으로 남기지만, 파일을 자동으로 삭제하지는 않습니다. 쓰기 작업에 실패한 프로그램이 즉시 종료되어 증상이 남지 않던 문제도 수정했습니다.
- **매니저** — 삭제하기 전에 삭제 대상 항목과 확보될 용량을 한 번 더 확인합니다. 「분석가」는 부하 카드에서 분리되어 별도 카드가 되었고, 화면이 팝업 대신 Live Agent 탭의 오른쪽 영역에 열리므로 분석이 진행되는 동안에도 다른 카드를 볼 수 있습니다.
- **에이전트** — PC의 에이전트 화면에서 시스템의 디스크 항목에 있던 「정리」 단추는 사라지고, 디스크 정리는 분석가에서 진행합니다.

## 개선 · 설정 › 사용자·권한 › 권한 관리에서 메뉴별 보기·관리 권한 지정

권한 관리에서 역할마다 볼 수 있는 화면을 정하는데, 위젯 단위라 상단 메뉴와 맞춰 보기 어려웠을 때 씁니다.

- **매니저** — 「메뉴 권한」 탭에서 메뉴별 「보기」와 「관리」(등록·수정·삭제) 권한을 켜거나 끕니다. 「보기」 권한이 없는 메뉴는 상단 메뉴와 검색 결과에 표시되지 않으며, 주소로 직접 접속해도 「권한 없음」이 표시됩니다.
- **매니저** — 변경한 권한은 로그인해 있는 관리자에게도 바로 적용됩니다. 계정의 역할을 바꾸면 다시 로그인하지 않아도 새 역할로 판정합니다.
- **서버** — 업데이트할 때 기존 위젯 권한을 메뉴별로 옮겨 담습니다. 최고 관리자 역할은 root 계정만 부여하거나 해제할 수 있습니다.

## 개선 · 화면 맨 위 검색창에서 IP·PC 이름·증상·이슈·프로세스 검색

어느 화면에서든 특정 PC나 프로그램을 찾아 들어가야 할 때 씁니다.

- **매니저** — IP·PC 이름·사용자 이름·부서·프로그램 이름을 입력하면 결과가 노드·증상·이슈·프로세스별로 구분되어 표시됩니다. Enter를 누르면 「검색 결과」 화면에서 유형별로 더 볼 수 있습니다.
- **매니저** — 증상과 프로세스는 최근 7일을 검색하고, 한 글자로 검색하면 노드만 찾습니다. 볼 권한이 없는 화면의 결과는 표시되지 않습니다.

## 개선 · 파일 › 파일함 화면을 폴더·목록·상세 3개 영역으로 재구성

파일함에서 일반 파일과 에이전트 업데이트 파일 같은 시스템 파일이 한 목록에 섞여 찾기 어려웠을 때 씁니다.

- **매니저** — 왼쪽에서 폴더나 시스템 파일 종류를 선택하면 가운데에 파일 목록이 표시되고, 파일을 선택하면 오른쪽에 상세 정보가 표시됩니다. 시스템 파일은 현재 적용된 버전을 별도로 표시합니다.
- **매니저** — 같은 이름이 있으면 새 버전으로 올릴지 다른 파일로 올릴지 선택합니다. 행을 왼쪽 폴더로 끌어 옮길 수 있고, 큰 파일은 끊겨도 이어서 올립니다.

## 개선 · 파일 › 배포에서 4단계로 새 배포를 만들고 실패한 PC가 있는 배포만 조회

여러 PC에 프로그램을 설치하거나, 끝난 배포 중 실패한 PC를 찾을 때 씁니다.

- **매니저** — 파일 확장자를 기준으로 설치 방식을 자동으로 선택하고, 마지막 단계에서는 설치할 항목과 대상 PC, 설치 시점을 문장으로 요약해 보여 줍니다. 목록 위의 「실패」 칩을 누르면 실패한 PC가 있는 배포만 표시됩니다.
- **매니저** — 실패한 PC가 있는 끝난 배포는 「완료」 대신 「실패 n」으로 표시됩니다. 배포를 열면 PC별 결과가 먼저 표시되고, 실패한 PC의 행에서 실패 내용과 설치 프로그램 출력을 확인합니다.
- **서버** — 그룹별 제한이나 역할별 대상 범위에 막힌 PC는 배포 대상에서 제외됩니다.

## 개선 · 노드 정보 › 정팀장의 추천 질문을 전날 많이 나온 질문으로 매일 변경

노드 정보 › 정팀장을 열어 무엇을 물을지 고를 때 씁니다.

- **정팀장** — PC가 켜져 있을 때와 꺼져 있을 때 표시하는 질문이 다르고, 질문 목록을 받지 못하면 이전에 사용하던 질문이 표시됩니다.
- **정팀장** — 정팀장이 학습 중이면 답을 기다리게 하지 않고 학습 중이라고 바로 알려 줍니다.

## 개선 · 네트워크 이슈 현황에서 소수 PC만 잠깐 실패한 대상까지 이슈로 열리던 문제

증상 › 현황 › 네트워크 이슈 현황에 열린 이슈 중 실제 장애가 아닌 것이 섞여 있을 때 씁니다.

- **서버** — 다음 중 하나일 때만 이슈를 엽니다: 응답한 PC가 2대 이상이고 모두 실패, 실패한 PC가 3대 이상, 한 네트워크 구역에서 응답한 PC의 절반 이상 실패. 이전보다 이슈가 적게 열립니다.
- **서버** — 이슈마다 최근 7일 증상 요약과 마지막으로 확인한 시각이 표시됩니다. 서버만 업데이트하면 됩니다.
- **매니저** — 대시보드 맨 위 왼쪽에 「네트워크 이슈 요약」 카드(열린 이슈 수·증상이 가장 많은 대상)가 추가됩니다.

## 개선 · Live Agent에서 분석가를 실행할 때마다 증상이 누적되던 문제

노드 상세 Live Agent에서 분석가를 여러 번 실행했는데 그때마다 증상이 생길 때 씁니다.

- **서버** — 보관할 결과는 「업로드」를 누릅니다. 업로드하지 않은 결과는 2시간 뒤 서버에서 삭제되며, 이후 해당 결과를 열면 「보관 기간이 지나 결과가 지워졌습니다」가 표시됩니다.
- **서버** — 삭제된 결과는 복구할 수 없습니다. 업데이트 전에 저장된 결과는 삭제하지 않습니다. 서버만 업데이트하면 됩니다.

## 개선 · 에이전트를 삭제하거나 업데이트할 때 블루스크린(0x7E)이 발생하던 문제

PC에서 에이전트를 삭제하거나 새 버전으로 올릴 때 블루스크린이 발생할 때 씁니다.

- **에이전트** — 이번 에이전트에는 수정된 드라이버가 포함되어 있습니다.
- **에이전트** — 각 PC의 에이전트가 1.6.242.1136으로 업데이트되어야 합니다.

## 개선 · 위험 경고가 없는 NVMe 데이터 오류가 「지금 백업」 이슈로 등록되던 문제

이슈 화면에 NVMe SSD의 「지금 백업」 이슈가 있는데, 디스크는 정상으로 동작할 때 씁니다.

- **룰** — 디스크에서 위험 경고가 발생하지 않은 데이터 오류는 「디스크 데이터 오류 기록」(지켜보기) 증상으로만 기록됩니다. 이미 열린 이슈는 다음 디스크 점검(하루 1번) 때 닫힙니다.
- **룰** — HDD 사용 시간이 5년(43,800시간)을 넘으면 「디스크 노후화」로 교체를 준비하라고 알립니다. 한 디스크가 여러 조건에 맞으면 조건마다 증상 행이 따로 생깁니다.
- **에이전트** — 가상 PC의 디스크를 「백업 필요」로 잘못 알리던 문제도 수정했습니다.
